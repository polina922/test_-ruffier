# test_ruffier
# Тест Руфье на первичную диагностику уровня здоровья по значениям пульса. 
** В данном эксперименте вам необходимо измерить свой пусль в спокойном состоянии, потом начать приседать полминуты и заново изменить пульс. И после небольшого отдыха в еще полминуты заново замерить пульс. После программа высчитает ваш уровень здоровья. **
