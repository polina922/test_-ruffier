# test_ruffier
# Тест Руфье на первичную диагностику уровня здоровья по значениям пульса. 
__В данном эксперименте вам необходимо измерить свой пусль в спокойном состоянии, потом начать приседать полминуты и заново изменить пульс. И после небольшого отдыха в еще полминуты заново замерить пульс. После программа высчитает ваш уровень здоровья.__
* На первой странице вводная информаиция.
* На второй странице сам эксперимент, где вы вводите свои значения пульса и возраст для оценки здоровья.
* На третьей странице результаты теста и вывод по состоянию вашего здоровья.
